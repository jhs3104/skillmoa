# ADR-0020: 기타에서 네 카테고리를 꺼내고 빈 스킬과 예제를 뺀다

- 상태: 채택
- 날짜: 2026-11-04
- ADR-0016의 카테고리 목록과 ADR-0018의 분류 호출을 보완한다.

## 맥락

공개 스킬 4,726개 중 `기타`에 279개가 있었다. 세부 분류를 세어 보니 한 주제에 몰려 있었다.

| 세부 분류 | 개수 |
|---|---|
| 금융 | 96 |
| 그 밖 | 80 |
| 비즈니스 운영 | 33 |
| 법률 | 31 |
| 오디오 | 29 |
| 건강 | 5 |
| 생활 | 5 |

금융은 `문서`(122개)와 비슷한 크기인데 `기타` 안에 묻혀 있었다. 운영자도 금융, 오디오·음악, 법률, 건강·생활을 따로 보고 싶어 했다.

`그 밖` 80개에는 사이트에 실을 이유가 없는 스킬도 섞여 있었다.

- 빈 안내 페이지: 예전 스킬이 옮겨졌다는 안내만 있다. `majiayu000/claude-skill-registry`의 9개가 모두 이렇다. `20260102-214532-trinity-…` 같은 이상한 이름도 여기서 나왔다.
- 읽을 수 없는 파일: 본문이 git-crypt로 암호화되어 있다.
- 예제: 파키스탄 시각, 두바이 날씨, 인사말처럼 기능을 보여 주려고 만든 견본이다.

이름이 숫자로 시작하는 스킬은 `360-feedback`, `1688-…`, `990-returns`처럼 대부분 정상이었다. 이름 모양으로는 거를 수 없다.

## 결정

- 카테고리 넷을 더한다. 기타에는 비즈니스 운영과 그 밖만 남는다.
  - 금융: 투자·트레이딩, 재무 분석, 회계·세무
  - 오디오·음악: 음성, 음악, 효과음·편집
  - 법률: 계약·약관, 규제·준법, 법률 업무
  - 건강·생활: 건강·의료, 생활·여행. 둘 다 5개라 하나로 묶는다.
- 분류 기준을 `t2`로 올린다. 다음 실행부터 요약은 그대로 두고 분류만 다시 정한다.
- 예전 세부 분류 `finance`, `audio`, `legal`은 값으로 남기고 새 카테고리에 연결한다. 다시 분류되기 전에도 새 카테고리에 보인다. `t2`는 이 값을 고르지 않고, 사이트 필터 칩에도 넣지 않는다.
- 기록에 남은 요약 프롬프트(v6)와 분류 기준(t1)이 보던 목록은 그때 모습 그대로 고정한다. 두 프롬프트의 해시를 테스트로 묶는다.
- 분류 호출이 `exclude`도 답한다. `placeholder`(본문 없음, 옮겨짐, 암호화)와 `demo`(그 자체로 쓸 일이 없는 견본)만 쓰고, 확실하지 않으면 비운다. 작은 도구, 특정 제품 전용, 재미용 스킬은 빼지 않는다.
- 사람이 정하는 목록을 `config.toml`의 `[exclude]`에 둔다. `repositories`, `skills`로 빼고 `keep`으로 AI 판단을 되돌린다. 수집과 요약은 그대로 하고 내보낼 때만 뺀다.
- 뺀 스킬은 순위 상한을 세기 전에 빠진다. 다른 스킬의 자리를 차지하지 않는다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 이름 패턴으로 거르기 | 숫자로 시작하는 정상 스킬이 더 많다 |
| 요약 프롬프트 v7로 판단하기 | 4,700개 요약을 모두 다시 만들어야 한다. 분류 호출은 요약문만 읽어 1,000개에 $0.2~0.4다 |
| 건강과 생활을 따로 두기 | 각 5개라 칩을 눌러도 목록이 빈약하다. 30개를 넘으면 다시 본다 |
| 수집 단계에서 제외 목록 적용 | 수집 코드가 넓게 바뀐다. 내보낼 때 빼도 사이트 결과는 같다 |

## 결과

- 전체 재분류는 실행당 상한 3,000개 기준으로 두 번의 정기 실행이면 끝난다. 비용은 $1~2로 예상한다.
- 실행 지표 `classify_excluded`와 로그의 "사이트에서 뺄 스킬"로 AI가 뺀 스킬을 확인한다. 잘못 빠졌으면 `keep`에 넣는다.
- 카테고리 칩이 13개에서 17개가 된다. 더 늘리기 전에 칩 배치를 다시 본다.
- 맞춤 추천의 목표에 `금융·법률·생활`을 더하고, `디자인·시각 자료`를 `디자인·영상·음악`으로 바꿔 오디오·음악을 묶는다. 목표를 고르면 그 카테고리만 추천하므로, 연결되지 않은 카테고리는 추천에 나오지 않는다. 기타를 뺀 모든 카테고리가 어떤 목표에든 연결되는지 테스트로 지킨다.
