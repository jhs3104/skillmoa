## 쓰는 규칙

- 형식: 제목, 상태, 맥락, 결정, 결과. Nygard 형식에 `검토한 대안` 표를 더했다. 새 기록은 [template.md](template.md)에서 시작한다.
- 제목은 결정을 한 문장으로 쓴다. "~한다"로 끝낸다.
- 상태는 `제안`, `채택`, `폐기`, `ADR-NNNN으로 대체` 중 하나다. 일부만 바뀌었으면 `채택. ~은 ADR-NNNN으로 대체`로 쓴다.
- 채택된 기록의 본문은 고치지 않는다. 결정이 바뀌면 새 기록을 쓰고, 옛 기록은 상태 줄만 바꾼다.
- 맥락과 결과에는 잰 숫자를 쓴다. 재지 않은 값은 예상이라고 밝힌다.
- 결과에는 감수하는 단점도 쓴다.

ADR-0013에는 이 규칙을 정하기 전에 덧붙인 "추가 결정"이 네 개 있다. 기록을 옮기지 않고 그대로 둔다. ADR-0024부터는 결정이 바뀔 때마다 새 기록을 쓴다.
