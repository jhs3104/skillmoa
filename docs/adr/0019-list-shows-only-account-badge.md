# ADR-0019: 목록에는 계정·API 키 배지만 둔다

- 상태: 채택
- 날짜: 2026-11-04
- ADR-0010, ADR-0015의 목록 표시 부분을 대체한다. 상세 페이지 표시는 그대로다.

## 맥락

목록 오른쪽 `AI 판단` 열에 코드 실행, 네트워크, 외부 계정 필요, 지침 문서만, 스크립트 포함, 미확인 배지를 보여 줬다. 운영자도 이 열이 무슨 뜻인지 알지 못했다. 설명은 홈 맨 아래 FAQ에만 있었다.

공개 스킬 4,726개를 세어 보니 배지가 스킬을 구별하지 못했다.

| 표시 | 비율 |
|---|---|
| 코드 실행 + 네트워크 | 50.3% |
| 코드 실행만 | 18.9% |
| 네트워크만 | 10.2% |
| 지침 문서만 | 19.4% |
| 스크립트 포함, 미확인 | 각 0.6% |
| 외부 계정 필요 (위와 겹침) | 14.4% |

10개 중 8개 행에 같은 앰버 배지가 붙어 경고처럼 보이기만 하고 비교에는 쓰이지 않았다.

## 결정

- 목록 행에는 `계정·API 키 필요` 배지만 둔다. 외부 서비스가 유료일 수 있다는 신호라서 설치 전에 가장 먼저 알아야 하고, 7개 중 1개에만 붙어 구별이 된다.
- 배지는 이름 줄의 저장소 이름 옆, `설치 명령 없음`과 같은 자리에 둔다. 넓은 목록의 `AI 판단` 열은 없앤다.
- 코드 실행, 네트워크 접속, 스크립트 파일 여부는 상세 페이지의 `AI가 SKILL.md를 읽고 판단` 묶음에 그대로 둔다. "안전"이나 "없음" 대신 "확인되지 않음"으로 쓰는 원칙도 그대로다.
- 필터의 "코드 실행·네트워크가 확인되지 않은 스킬만"은 남긴다. 목록에 배지가 없어도 이 기준으로 고르려는 사용자가 있다.
- `외부 계정`이라는 표현은 `계정·API 키`로 바꾼다. 무엇이 필요한지 바로 읽힌다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 배지를 모두 두고 문구와 툴팁만 고치기 | 이름이 알기 쉬워져도 80%의 행에 같은 배지가 붙는 문제는 그대로다 |
| `지침 문서만`도 목록에 남기기 | 표시가 둘로 늘면 다시 열이 필요하다. 상세 페이지에서 확인할 수 있다 |
| 목록에서 AI 판단을 모두 빼기 | 유료 서비스가 필요한 스킬을 목록에서 알아볼 수 없다 |

## 결과

- 넓은 목록에서 172px 열이 빠져 요약 문장이 더 길게 보인다.
- 수집기와 데이터 형식은 바뀌지 않는다. 판단 값은 상세 페이지와 필터가 계속 쓴다.
