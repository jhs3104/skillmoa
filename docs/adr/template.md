# ADR-NNNN: 결정을 한 문장으로 쓴다

- 상태: 제안
- 날짜: YYYY-MM-DD

## 맥락

이 결정을 하게 만든 상황과 제약을 쓴다. 판단은 넣지 않고 사실만 쓴다. 잰 숫자가 있으면 넣는다.

## 결정

- 무엇을 하기로 했는지 "~한다"로 쓴다.
- 설정값, 파일, 한도처럼 확인할 수 있는 것을 적는다.
