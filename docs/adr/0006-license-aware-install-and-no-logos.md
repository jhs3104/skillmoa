# ADR-0006: 라이선스에 따라 설치 안내를 나누고 저장소 로고를 쓰지 않는다

- 상태: 채택
- 날짜: 2026-11-01

## 맥락

상세 페이지는 모든 스킬에 `git clone`과 `cp -R` 명령을 보여 주었다. 복사는 사용자의 터미널에서 일어나지만, 사이트는 복사 명령을 직접 만들어 제공한다. 독점 라이선스 스킬에는 복제와 추출을 금지하는 경우가 있고, 라이선스가 없는 저장소는 복제 권리가 불분명하다. 샘플 12개에도 독점 1개, 미표기 1개, `LICENSE.txt` 참고 5개가 있다.

목록은 GitHub 소유자 프로필 이미지를 보여 주었다. 이 이미지에는 Anthropic처럼 사용 조건이 있는 회사 로고가 포함되어, 제휴처럼 보일 수 있다.

## 결정

- `lib/license.ts`가 라이선스를 `open`, `check`, `restricted`로 나눈다. 아는 오픈소스 라이선스만 `open`이다.
- `restricted`는 설치 명령을 숨기고 이유와 저장소 링크만 보여 준다.
- `check`는 설치 명령을 두되 위에 확인 안내를 표시한다.
- 저장소 이미지는 쓰지 않는다. 그 자리에는 카테고리 라벨을 둔다 (ADR-0009).
- 푸터에 비제휴 문구를 넣고, 삭제 요청 메일은 `CONTACT_EMAIL`을 정하면 표시한다.

## 검토한 대안

| 대안 | 장점 | 기각 이유 |
|---|---|---|
| 모든 스킬에 명령 유지 | 전환이 단순하다 | 금지 조건이 있는 스킬까지 복제를 돕게 된다 |
| 오픈소스 스킬만 목록에 노출 | 위험이 가장 낮다 | 유명 스킬이 사라지고, 링크와 요약까지 막을 근거는 약하다 |
| 로고에 면책 문구만 추가 | 화면이 그대로다 | 상표권자의 사전 승인 요건을 해결하지 못한다 |

## 결과

- 일부 유명 스킬은 사이트에서 바로 설치할 수 없다. 원본 저장소로 보내는 비용을 감수한다.
- 목록이 덜 화려해진다. 대신 페이지마다 300개까지 나가던 github.com 이미지 요청이 없어진다.
- 법률 자문이 아니다. 광고를 켜기 전에 변호사 확인이 필요하다.
