# ADR-0022: 소식 페이지에 도구 업데이트와 스킬 동향을 나눠 싣는다

- 상태: 채택 (세 단계 모두 구현)
- 날짜: 2026-11-04

## 맥락

에이전트 도구와 스킬은 매일 바뀐다. 운영자는 "AI 뉴스" 같은 소식을 넣고 싶어 했다. 다만 언론 기사를 모아 요약하면 저작권 문제가 있고, CLAUDE.md의 "원문 번역·복사 금지"와도 맞지 않는다. 대량으로 만든 AI 요약은 AdSense 심사에서도 불리할 수 있다.

이 사이트만 줄 수 있는 소식은 두 가지다.

- 도구 업데이트: 사이트가 설치 명령을 주는 Claude Code, Codex, Cursor의 공식 변경 기록
- 스킬 동향: 이미 모으는 데이터로 계산하는 새 스킬과 스타 변화

이미 `/new/`에 최근 발견한 스킬 목록이 있다.

## 결정

- `/news/` 페이지 하나에 탭 두 개를 둔다. `도구 업데이트`는 날짜별 글 피드, `스킬 동향`은 숫자와 스킬 목록 행이다. 모양이 달라 섞이지 않는다.
- 메뉴는 `스킬 · 소식 · 맞춤 추천 · AI 찾기`다. `새 스킬` 자리를 `소식`이 대신하고, 새 스킬 목록은 스킬 동향 탭에서 들어간다. `/new/` 주소는 그대로 둔다.
- 도구 업데이트의 출처는 공식 기록만 쓴다.
  - Claude Code: `anthropics/claude-code`의 `CHANGELOG.md`
  - Codex: `openai/codex`의 GitHub Releases 중 정식 버전. 알파는 본문이 거의 비어 있다.
  - Cursor: `cursor.com/changelog/rss.xml`
- 화면에서는 `도구` 대신 `에이전트`라고 부른다. 탭 이름은 `에이전트 업데이트`다. `AI 업데이트`는 AI 뉴스 전반으로 읽혀 쓰지 않는다. 처음 여는 탭은 에이전트 업데이트다.
- 도구 업데이트 탭에는 `전체 · Claude Code · Codex · Cursor` 필터 칩을 둔다. 고른 도구는 주소(`/news/?tool=claude-code`)에 남겨 그대로 공유할 수 있다. 업데이트 항목마다 도구 값을 저장한다.
- 도구별로 하루에 한 번, 그날 나온 버전을 묶어 Haiku가 한국어 2~3줄로 새로 쓴다. 스킬과 에이전트 사용자에게 의미 있는 변경만 고르고 원문 링크를 붙인다. 프롬프트는 버전으로 관리하고 하루 상한을 둔다.
- 스킬 동향 중 새 스킬 수, 늘어난 분야, 눈에 띄는 새 스킬은 사이트가 `skills.json`의 발견일·분류·스타로 계산한다.
- 스타 급상승은 기록이 있어야 한다. collector가 실행마다 저장소 스타를 `collector/state/star_history.json`에 하루 한 값으로 남기고 35일만 보관한다. 기록의 마지막 날을 기준으로 7일 전 기록이 있는 저장소만 비교해 `site/src/data/news.json`에 상위 10개를 낸다. 사이트에 실린 저장소만 싣는다.

- 도구 업데이트는 스킬 수집과 다른 워크플로(`tool-news.yml`, 6시간마다)에서 `--tool-news`로 처리한다. 스킬 수집은 40~80분 걸리고 정기 실행이 빠지기도 해서, 묶어 두면 소식까지 늦어지거나 멈춘다.
- 두 워크플로가 같은 파일을 고치지 않게 나눈다. 스킬 수집은 `news.json`(급상승)을, 도구 소식은 `collector/state/tool_updates.json`과 `site/src/data/tool-updates.json`을 쓴다. 도구 소식의 호출 수도 `meta.json`이 아니라 `tool_updates.json`에 센다. 그래서 두 실행이 동시에 끝나도 rebase가 충돌하지 않는다.

## 단계

1. collector: 스타 기록과 급상승 export. AI를 쓰지 않는다.
2. collector: 도구 업데이트 소스 세 개와 요약 프롬프트 v1. `summary-reviewer`로 검증한다.
3. site: `/news/` 페이지와 메뉴. impeccable 순서를 거친다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| AI 뉴스 전반을 모으기 | 저작권과 AdSense 위험이 크고 사이트 주제에서 벗어난다 |
| 버전마다 요약 | Claude Code는 하루에도 여러 버전이 나와 목록이 길어진다 |
| 주간 요약 | 최신 변경을 늦게 알린다 |
| `소식`을 다섯 번째 메뉴로 | 375px 머리글이 비좁아진다 |
| 스타 기록을 저장소 레코드에 함께 저장 | `repositories.json`의 모든 줄이 매일 바뀌어 커밋 차이가 커진다. 파일을 나눈다 |

## 결과

- 급상승은 기록이 7일 쌓인 뒤부터 나온다. 그 전에는 빈 목록이다.
- `star_history.json`은 저장소 약 900개 × 35일로, 수백 KB 수준이다.
