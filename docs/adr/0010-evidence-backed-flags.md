# ADR-0010: AI 표시에 원문 근거를 요구하고 외부 계정 필요 여부를 더한다

- 상태: 채택
- 날짜: 2026-11-02

## 맥락

실제 요약 10개를 원문과 대조하니 2개만 통과했다. 네트워크 표시가 false인 8개 중 4개가 원문과 어긋났고, CDN, 폰트 다운로드, 외부 연동, 대체 경로의 패키지 설치를 놓쳤다. 코드 실행 기준도 들쭉날쭉했고, 표시로 전할 내용이 요약 본문의 안심 문구로 나왔다. 유료 서비스가 필요한 스킬을 구분하는 항목도 없었다.

## 결정

- 프롬프트를 v2로 올린다. 판정 기준을 정의하고, 조건부 경로도 true로 한다.
- 표시마다 근거 구절을 값보다 먼저 받는다. 코드로 근거가 원문에 있는지 확인하고, 없으면 다시 요청한다.
- 끝까지 근거가 확인되지 않으면 요약을 버리지 않고 표시를 켠 채 둔다. 경고를 스킬째 잃는 쪽이 더 위험하다. 이 건수는 실행 지표로 남긴다.
- 근거는 상태에만 두고 사이트로 내보내지 않는다.
- 본문의 안심 표현은 코드로 거부한다.
- 라이브러리 언급만 있거나, 결과물의 코드를 에이전트가 실행하지 않으면 코드 실행이 아니다.
- `requires_external_account`를 더한다. 가격과 무료 여부는 판단하지 않고, `무료`라고 쓰지 않는다.

v3에서 다음을 더했다. v2도 20개 중 5개에서 실제 동작을 놓쳤기 때문이다.

- 원문의 코드 구간에서 명령을 찾아, AI가 놓친 코드 실행과 네트워크 표시를 코드로 켠다. 켜기만 하고 끄지는 않는다. 과경고가 누락보다 낫다.
- 127.0.0.1과 localhost만 쓰는 접속은 네트워크로 세지 않는다. 배지는 외부 접속으로 읽히기 때문이다.
- 외부 계정은 반드시 필요할 때만 켠다. 선택 사항이거나 대안 경로가 있으면 끈다.

v4에서는 문장으로만 적힌 동작을 다룬다. v3는 표본을 다섯 저장소로 넓히자 과경고 없이 6건을 놓쳤고, 대부분 명령 없는 문장에 있었다.

- 코드 검사가 PR 번호, 원격 리비전, 업데이트 확인, 검증 명령 같은 본문 표현도 찾는다.
- 모델의 추론 강도를 low에서 medium으로 올린다.
- 같은 저장소의 다른 스킬에 위임한 동작은 따라가지 않는다. 표시는 SKILL.md 한 파일만 본 결과다.

v5에서 제품 전용 스킬의 이름을 첫 문장에 쓰게 하고, 외부 계정 제외 범위를 좁히고, 이슈와 PR 검토를 코드 실행과 네트워크로 본다. 추가 시험 대신 첫 수집 묶음에서 다양한 저장소를 표본으로 뽑아 검수한다. 묶음 비용이 약 $1.6로 작고, 20개보다 대표성이 높기 때문이다.

## 검토한 대안

| 대안 | 장점 | 기각 이유 |
|---|---|---|
| 프롬프트 문구만 강화 | 스키마가 그대로다 | 틀려도 알아챌 수 없다 |
| 유료 여부를 `유료`와 `무료`로 표시 | 사용자에게 단순하다 | 무료 구간과 가격은 SKILL.md로 알 수 없고 수시로 바뀐다 |
| 분류 전용 모델을 따로 호출 | 호출당 비용이 낮다 | 요약 호출에서 함께 얻으므로 줄일 비용이 없고 공급자만 늘어난다 |
| 코드 실행 표시를 번들 파일까지 분석 | 정확도가 오른다 | 수집량과 비용이 커진다. 나중에 재검토한다 |

## 결과

- 출력 토큰이 늘어 스킬당 비용이 조금 오른다.
- 표시를 켜고 근거를 내지 않으면 재시도하고, 끝까지 실패하면 그 스킬은 공개되지 않는다.
- 첫 검증에서 켠 표시의 근거가 원문과 글자만 달라 스킬이 버려지는 문제가 나와, 마크업과 말줄임표를 무시하고 비교한다.
- 표시는 여전히 SKILL.md만 본 결과다. 번들 스크립트의 실제 동작은 보증하지 않는다.
