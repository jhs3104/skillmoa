# ADR-0007: 사이트 이름을 스킬모아로 정한다

- 상태: 채택
- 날짜: 2026-11-01

## 맥락

첫 이름 스킬서가는 제작자가 마음에 들어 하지 않았고, 도메인을 사기 전에 바꾸는 비용이 가장 낮았다. 영어 일반어를 조합한 후보는 대부분 같은 분야에서 이미 쓰이고 있었다.

## 결정

- 이름은 스킬모아, 영어 표기는 Skillmoa로 쓴다. 스킬을 모아 둔 곳이라는 뜻이다.
- Worker와 패키지 이름도 `skillmoa`로 맞춘다.
- 도메인은 `skillmoa.com`을 쓴다. 영어판을 추가하면 같은 도메인의 `/en/`을 쓴다.

## 검토한 대안

| 대안 | 장점 | 기각 이유 |
|---|---|---|
| Skillverse | 짧고 영어로 바로 읽힌다 | `.com` 호가가 $20,000이고, 교육 서비스에서 흔하다 |
| 스킬 유나이티드 | 같은 분야 충돌이 없다 | `.com`이 없고 skill/skills 철자가 헷갈린다 |
| 스킬픽 | 추천 기능과 잘 맞는다 | `.com`이 없고 같은 분야에 agentskillpicks가 있다 |
| Agent Skills Hub, Agentrove, AI Room | 뜻이 영어로 바로 읽힌다 | 같은 이름이 같은 분야에 이미 있다 |

## 결과

- 영어권에서는 `moa`의 뜻이 바로 전달되지 않는다. 첫 출시는 한국어 사용자가 대상이라 감수한다.
- 비슷한 이름의 핀란드 학습 앱 회사 Skillmo가 있지만 분야가 다르다.
- 등록 전 도메인과 상표 확인은 사람이 직접 한다.
