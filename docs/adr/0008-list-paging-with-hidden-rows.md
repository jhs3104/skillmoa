# ADR-0008: 목록은 50개씩 펼치고 나머지 행은 숨겨 둔다

- 상태: ADR-0012로 대체
- 날짜: 2026-11-01

## 맥락

첫 출시 목록은 300개다. 한 번에 모두 보여 주면 모바일에서 스크롤이 지나치게 길고 필터까지 돌아가기 어렵다. 그렇다고 페이지를 나누면 브라우저 안의 키워드 검색이 300개 전체를 찾지 못한다.

## 결정

- 정적 HTML에는 모든 행을 두고, 51번째 행부터 `hidden`으로 시작한다.
- `더 보기`는 50개씩 펼친다. 검색, 정렬, 필터를 바꾸면 처음 50개로 돌아간다.
- 펼친 개수는 `history.state`에 둔다. 상세에서 돌아와도 유지되고, 공유 링크에는 들어가지 않는다.
- 자바스크립트가 없으면 `noscript` 스타일로 모든 행을 보여 준다.

## 검토한 대안

| 대안 | 장점 | 기각 이유 |
|---|---|---|
| 300개 전부 표시 | 구현이 없다 | 모바일 스크롤이 길다 |
| 서버 페이지 분할 | HTML이 작다 | 검색이 현재 페이지만 찾거나 별도 색인이 필요하다 |
| 무한 스크롤 | 조작이 없다 | 푸터에 닿을 수 없고 키보드 사용자가 불리하다 |

## 결과

- HTML 크기는 그대로다. 숨긴 행은 그리지 않을 뿐이라 전송량은 줄지 않는다.
- 전체 수집으로 규모가 커지면 D1과 온디맨드 렌더링으로 바꿔야 한다.
