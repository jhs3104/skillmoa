# ADR-0009: 초록 띠를 버리고 카테고리 색 라벨로 화면을 다시 짠다

- 상태: 채택
- 날짜: 2026-11-02

## 맥락

첫 디자인은 짙은 초록 띠, 종이색 바탕, 테두리 상자로 이루어졌다. 제작자는 이 화면이 올드해 보인다고 판단했다. 첫 글자 타일은 저장소 소유자가 겹치면 같은 글자가 반복되어 정보가 거의 없었다.

## 결정

- 네 시안을 실제 화면 내용으로 만들어 비교했고, 제작자가 색 라벨을 골랐다.
- 순백 바탕, 거의 검은 글자, 코발트 강조, 굵은 큰 제목으로 바꾼다. 테두리 상자 대신 얇은 선과 가라앉은 회색 면을 쓴다.
- 카테고리마다 단색 라벨을 두고, 목록 행과 필터에 같은 색을 쓴다. 첫 글자 타일은 없앤다.
- 홈은 제목과 검색칸을 나란히 두고 필터와 목록을 전폭으로 깐다.
- ADR-0005의 초록 띠 유지 결정을 대체한다. AI 찾기를 분리한 결정은 그대로다.

## 검토한 대안

| 대안 | 장점 | 기각 이유 |
|---|---|---|
| 앱 피드 | 가장 익숙하고 현대적이다 | 개성이 약하고 첫 화면의 행 수가 줄어든다 |
| 심야 노선도 | 개발자에게 친숙한 어두운 화면이다 | 입문자에게 무겁고 긴 요약을 읽기 어렵다 |
| 개발자 도구 표준 | 깔끔하고 검증되었다 | 비슷한 디렉터리와 구분되지 않는다 |

## 결과

- 색이 13개로 늘어 산만해질 위험이 있다. 색은 카테고리와 주의 표시에만 쓴다.
- 라벨 글자가 색 대비를 지키도록 카테고리마다 글자색을 정해 둔다.
- 카테고리가 늘면 구분되는 색을 새로 골라야 한다.
