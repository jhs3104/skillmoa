# 스킬 발견 소스 추가

## 절차

1. 소스 형식을 조사한다: 데이터 위치, 구조, 인증 필요 여부, 호출 제한, 저장소·스킬 경로를 얻는 방법. 실제 응답이나 파일을 직접 확인한다.
2. `collector/src/collector/sources/`에 어댑터를 추가한다. 소스별 처리는 어댑터 안에 두고, `domain/` 수정은 꼭 필요한 경우로 한정한다.
3. 기존 소스와의 중복 제거를 확인한다. 같은 저장소·스킬 경로가 두 소스에서 나와도 레코드가 하나인지 테스트로 검증한다.
4. `uv run pytest`를 통과시킨다.
5. `run-collector-small`로 검증한다. 새 소스에서 온 스킬이 샘플에 포함되어야 한다.
6. ADR 필요 여부를 판단한다. 새 외부 의존, `domain/` 변경, 수집 범위·비용을 바꾸는 결정이면 `docs/adr/`에 기록한다. 그렇지 않으면 생략 이유를 보고에 적는다.

새 소스의 스킬이 샘플에 있고, 중복 제거 테스트가 통과하고, ADR 판단 결과가 보고에 있으면 완료다.
